### What I learned

- claude.md contains the project instructions
- claude --continue is to resume using claude on the project I am working on it
- How to start a new project with Claude Code:
  1. Create a repository on GitHub (private for now) with a README and the VisualStudio .gitignore.
  2. Clone it: `cd D:\Development\Learning` → `git clone https://github.com/AhmadAtat/knowledge-assistant.git` → `cd knowledge-assistant`
  3. Run `claude`; on first start, sign in with the Claude account and trust the folder.
  4. Press Shift+Tab to switch modes: plan mode (Claude only plans), manual mode (Claude asks before every change).
